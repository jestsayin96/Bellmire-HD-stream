The seven .glb models in this directory are from Quaternius's "Ultimate RPG Items Pack" (Aug 2019):
  sword_golden, sword_big_golden, dagger_golden, axe_small_golden, axe_double_golden,
  hammer_double_golden, bow_golden
Converted by the game build lane (S45, 18 Nov 2026) from the pack's own .blend files with Blender 5.2
(glTF binary export, Y-up, transforms applied). Geometry unchanged.
CORRECTION (S46, 18 Nov): the S45 export kept the material NAMES but wrote no colour - every material had no
baseColorFactor (glTF default = white, metallic 1). The pack has no UVs and no texture; its colour lives in each
material's flat Base Color. S46 wrote those values into each material's pbrMetallicRoughness (baseColorFactor
from the .blend, metallic 0, roughness as in the .blend). Geometry and binary buffer untouched.
